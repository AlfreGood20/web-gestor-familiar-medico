# Aplicacion web gestor familiar medico

## Requesitos 
- Node.js v22+
- git 2.47+
- VS CODE

## Pasos para su instalacion
1. Clonar el repositorio
```bash
git clone https://github.com/AlfreGood20/web-gestor-familiar-medico.git
```

2. Entrar al proyecto
```bash
cd <nombre-carpeta>
```

3. Instalar dependecias
```powershell
npm install
```

4. Correr el servidor
```
npm run dev
```

> **IMPORTANTE:** En los modulos de `services`cambiar la url de la api por la url correspodiente (`const API_URL = 'URL API';`) por defecto tenemos una local en puerto 8080.
